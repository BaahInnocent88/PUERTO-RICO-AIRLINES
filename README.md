Puerto Rico Airlines Website

This is a simple and elegant static web page for Puerto Rico Airlines, built with HTML and CSS only.  
It showcases flight information, group trip deals, and discount flight options in a clean and user-friendly layout.

Project Overview

The website is designed to demonstrate a basic airline homepage using flexbox layouts and responsive design principles.  
It includes a header navigation bar, three main promotional sections, and an informational section about discount offers.

Features

Header Navigation Bar:
  Contains links to Home, Flight, Support, and Login.

Main Body Section:  
  Displays three informational boxes:
  Flights – Direct daily flights  
  Group Trips – Family and large group packages  
  Discount Flights – Single ticket low-rate offers  

  About Section:  
  A separate section below the main boxes describing additional discount information.

  Buttons with Hover Effects:  
  Interactive buttons styled with color transitions for each section.

  Responsive Layout:
  Uses **Flexbox** to align and wrap boxes neatly, ensuring proper display on small and large screens.

  Project Structure
index.html: Main HTML file containing the structure
style (in head)  Internal CSS for styling and layout


Design Details

  Theme Colors:
  - Background: rgb(242, 198, 144) (warm peach)
  - Box & Button: rgb(177, 112, 34) (brown tone)
  - Hover Accent: rgb(238, 215, 11) (golden yellow)
  - Header: bisque

  Fonts: 
  Tahoma / Geneva / Verdana (clean sans-serif family)

  Layout:
  Built with display: flex for alignment and responsiveness.

  Key Section Classes:
    .main-body → Main container using flexbox
    .main-mid → Individual info cards (Flights, Group Trips, Discount Flights)
    .about-learn → Lower informational section
    .btn → Uniform button style
